# Data

The full datasets used in this project are not stored in this repository due to file size.

Small samples are included to show the structure of the data used in the analysis:

- `game_events_sample.csv` — shot-level event data
- `general_game_stats_sample.csv` — match-level summary data

The complete files can be downloaded from the original Kaggle dataset:

[Player Stats Per Game - Understat](https://www.kaggle.com/datasets/codytipton/player-stats-per-game-understat)

The notebook expects the full files to be named:

- `game_events.csv`
- `general_game_stats.csv`
